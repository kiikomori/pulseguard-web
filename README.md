# Pulseguard
Pulseguard is een nieuw, opkomend medisch wearable-systeem. Het is een horloge dat onder andere hartslag, temperatuur, stappen en SpO2-concentratie meet die door middel van een API het data doorstuurt. Het PulseGuard-horloge wordt ondersteund door de PulseGuard health tracker website, die in dit repo open source wordt gemaakt. Op onze website, [pulseguard-technologies.nl](https://www.pulseguard-technologies.nl/), vind je meer informatie over ons project.
